## 🎮 О игре

**Space Shooter** — это процедурно-генерируемый космический шутер с бесконечным миром. Управляй кораблём с инерционной физикой, сражайся с врагами, собирай бонусы, улучшай корабль и исследуй бескрайний космос.

### 🎯 Особенности
- 🌌 **Бесконечный мир** — процедурная генерация чанков с сохранением на диск.
- 🚀 **Инерционная физика** — реалистичное управление кораблём.
- 👾 **7 типов врагов** — разные стратегии и поведение.
- 💎 **6 типов бонусов** — здоровье, щит, тройной выстрел, ускорение, бомба, магнит.
- 🗺️ **Мини-карта** — ориентация в бесконечном мире.
- ⚙️ **Система волн** — постепенное усложнение игры.
- 🏆 **Рекорды** — сохраняются между сессиями.
- 🖱️ **Управление мышкой** — прицеливание и стрельба.

## 🎯 Управление

| Клавиша | Действие |
|---------|----------|
| W / ↑ | Газ |
| A / ← | Поворот налево |
| D / → | Поворот направо |
| Space / ЛКМ | Стрельба |
| Shift | Варп (ускорение x5) |
| P | Пауза |
| ESC | Меню |


**Управление мышкой:**
- Движение мыши — поворот корабля.
- Левый клик — стрельба.

## 📦 Установка и запуск

### 1. Клонируй репозиторий
```bash
git clone https://github.com/PsihoPAD13/space-shooter.git
cd space-shooter
```

### 2. Установи зависимости
```bash
pip install pygame
```

### 3. Запусти игру
```bash
python main.py
```
